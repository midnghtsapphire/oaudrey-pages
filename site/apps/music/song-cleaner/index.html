Cut cleaner

Runs only in your browser. Your song is not uploaded anywhere. The original file is never changed.

  1. Choose a song (WAV or MP3).
  2. Listen to each flagged spot. Leave it on Cut, or press Keep.
  3. Optionally cut a section, fix a bad note, or try a polish preset. Preview first.
  4. Download the report. If anything changed, you can also download a cleaned WAV.

Drop a file here, or choose one from this computer.

Nothing is sent to a server. If the file is large, give the page a few seconds to listen.
